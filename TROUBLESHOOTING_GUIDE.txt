2. Click "Console" tab
3. Try to add/edit product
4. Look for RED error messages

- "500 Internal Server Error" → PHP error
- "Failed to load resource" → Missing file
- AJAX errors → Check network tab

CHECK 2: PHP Error Log
---------------------
1. Open WAMP tray icon
2. Click "PHP" → "PHP Error Log"
3. Look for recent errors
4. Common issues:

   - Warning → Non-critical issue

========================================
COMMON ISSUES & SOLUTIONS:
========================================

ISSUE: "Access Denied" Error
SOLUTION:
- Make sure you're logged in as admin
- Try logout and login again
- Clear browser cookies

ISSUE: Image Upload Fails
SOLUTION:
- Check folder exists: assets/images/products/
- Check folder permissions (writable)
- Check php.ini settings:
  upload_max_filesize = 10M
  post_max_size = 10M

ISSUE: "jQuery is not defined"
SOLUTION:
- Check internet connection
- jQuery loads from CDN in footer.php
- Try hard refresh (Ctrl+F5)

ISSUE: SweetAlert Not Showing
SOLUTION:
- Check browser console for errors
- SweetAlert2 loads from CDN in header.php
- Try clearing browser cache

ISSUE: Form Doesn't Submit
SOLUTION:
- Open browser console (F12)
- Look for JavaScript errors
- Check if product_save.php exists
- Verify path: admin/product_save.php
