========================================
  ADMIN DEBUGGER - HOW TO USE
========================================

YOU CAN'T CLICK BUTTONS? USE THIS DEBUGGER!

========================================
STEP 1: RUN THE DEBUGGER
========================================

1. Open your browser

2. Go to this URL:
   http://localhost/DineClick/admin/debug.php

3. You will see a diagnostic page with:
   ✓ System health check
   ✓ Interactive test buttons
   ✓ Console output
   ✓ Error messages

========================================
STEP 2: READ THE RESULTS
========================================

Look at the top of the page:

GREEN CARDS (Passed Checks):
- These are working correctly
- Example: "✓ jQuery is loaded"

RED CARDS (Critical Errors):
- These MUST be fixed
- Example: "✗ User is NOT admin"

YELLOW CARDS (Warnings):
- Optional improvements
- System may still work

========================================
STEP 3: RUN INTERACTIVE TESTS
========================================

Click each button and watch the console:

1. "Test jQuery" 
   - Should show: ✓ jQuery is loaded
   - If ✗: Internet connection problem

2. "Test SweetAlert"
   - Should open a popup
   - If no popup: CDN blocked

3. "Test Button Click"
   - Shows if clicks are working
   - Checks CSS blocking

4. "Test AJAX Save"
   - Tests connection to product_save.php
   - Shows actual error messages

5. "Test AJAX Delete"
   - Tests connection to product_delete.php
   - Verifies file exists

========================================
STEP 4: COMMON ISSUES & FIXES
========================================

ISSUE: "User is NOT admin"
FIX:
- Logout completely
- Login again with: admin@dineclick.com / admin123
- Or run: http://localhost/DineClick/generate_password_hash.php

ISSUE: "jQuery is NOT loaded"
FIX:
- Check internet connection
- jQuery loads from CDN (needs internet)
- Try hard refresh: Ctrl+F5

ISSUE: "Database error"
FIX:
- Check WAMP is running (GREEN icon)
- Verify database exists: dineclick_db
- Run: http://localhost/DineClick/setup_check.php

ISSUE: "Upload directory NOT writable"
FIX:
- Right-click: c:\wamp64\www\DineClick\assets\images\products\
- Properties → Security → Edit
- Add "Users" group with Write permission

ISSUE: "AJAX request failed"
FIX:
- Check file exists: admin/product_save.php
- Check file exists: admin/product_delete.php
- Look at console output for specific error

========================================
STEP 5: ANALYZE CONSOLE OUTPUT
========================================

The black console box shows:

GREEN TEXT = Success
RED TEXT = Error
YELLOW TEXT = Warning

Example Good Output:
[10:30:15] Testing jQuery...
[10:30:15] ✓ jQuery is loaded (version: 3.6.0)
[10:30:15] ✓ $ selector works
[10:30:15] ✓ Click event works

Example Bad Output:
[10:30:15] Testing AJAX...
[10:30:15] ✗ AJAX request failed
[10:30:15] Error: 404 Not Found
[10:30:15] File missing: product_save.php

========================================
STEP 6: SPECIFIC CLICK ISSUE TESTS
========================================

If buttons don't respond to clicks:

Test A: "Test Button Click"
- Click this button
- If it works: jQuery is fine
- If it doesn't: jQuery problem

Test B: Check z-index
- Console will show z-index value
- If negative: CSS blocking clicks

Test C: Check pointer-events
- Console will show pointer-events value
- If "none": CSS blocking clicks

========================================
STEP 7: BROWSER-SPECIFIC FIXES
========================================

Chrome/Edge:
1. Press Ctrl+Shift+Delete
2. Clear "Cached images and files"
3. Click "Clear data"
4. Press Ctrl+F5 to reload

Firefox:
1. Press Ctrl+Shift+Delete
2. Check "Cache"
3. Click "Clear Now"
4. Press Ctrl+F5 to reload

========================================
WHAT THE DEBUGGER CHECKS:
========================================

✓ Session Status
  - Are you logged in?
  - Do you have admin rights?

✓ Database Connection
  - Can connect to MySQL?
  - Can query products table?
  - Do categories exist?

✓ File System
  - Do required files exist?
  - Are folders writable?
  - Can upload images?

✓ PHP Configuration
  - PHP version
  - Upload limits
  - Error settings

✓ JavaScript Libraries
  - jQuery loaded?
  - SweetAlert2 loaded?
  - FormData supported?

✓ AJAX Connectivity
  - Can reach product_save.php?
  - Can reach product_delete.php?
  - Are responses valid JSON?

✓ Click Events
  - Do buttons respond?
  - Is CSS blocking clicks?
  - Are elements visible?

========================================
AFTER RUNNING DEBUGGER:
========================================

If ALL CHECKS PASS:
→ Go back to products.php
→ Try again
→ Buttons should work

If ERRORS FOUND:
→ Fix errors shown in red
→ Re-run debugger
→ Repeat until all pass

If STILL NOT WORKING:
→ Take screenshot of debugger page
→ Note which test fails
→ Check console output
→ Look for specific error message
