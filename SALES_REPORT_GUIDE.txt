========================================
  SALES REPORT - HOW IT WORKS
========================================

The "Generate Report" button filters sales data by date range.

========================================
HOW "GENERATE REPORT" WORKS:
========================================

STEP 1: User Selects Date Range
--------------------------------
1. Admin goes to: http://localhost/DineClick/admin/reports.php
2. Sees two date fields:
   - Start Date (default: first day of current month)
   - End Date (default: last day of current month)
3. Can change dates to any range

STEP 2: User Clicks "Generate Report"
-------------------------------------
1. Form submits with GET method
2. URL becomes: reports.php?start_date=2024-01-01&end_date=2024-01-31
3. Page reloads with new data

STEP 3: System Queries Database
-------------------------------
The page runs 3 main queries:

A. SUMMARY DATA (Lines 13-24)
   - Total Orders (all orders in date range)
   - Total Revenue (only Delivered orders)
   - Cancelled Orders
   - Average Order Value

B. TOP PRODUCTS (Lines 27-40)
   - Top 5 best-selling products
   - Shows units sold
   - Shows revenue per product
   - Only counts Delivered orders

C. DAILY SALES CHART (Lines 42-65)
   - Loops through each day in date range
   - Gets revenue for each day
   - Creates array for Chart.js
   - Shows daily sales bar chart

STEP 4: Display Results
-----------------------
1. Summary Cards show totals
2. Chart shows daily breakdown
3. Table shows top products
4. All filtered by selected date range

========================================
DEFAULT BEHAVIOR:
========================================

When you first open reports.php:
- Start Date = First day of current month
  Example: If today is Oct 30, 2024
  Start Date = October 1, 2024

- End Date = Last day of current month
  Example: October 31, 2024

This shows "This Month's Report" by default.

========================================
WHAT DATA IS SHOWN:
========================================

📊 SUMMARY CARDS:
-----------------
1. Total Orders
   - ALL orders (Pending, Preparing, Delivered, Cancelled)
   - Formula: COUNT(*) from orders table

2. Total Revenue
   - ONLY Delivered orders counted
   - Formula: SUM(total_amount) WHERE status = 'Delivered'
   - Why? Pending/Cancelled orders don't generate revenue

3. Average Order Value
   - Average of Delivered orders only
   - Formula: AVG(total_amount) WHERE status = 'Delivered'
   - Helps track customer spending

4. Cancelled Orders
   - Number of cancelled orders
   - Formula: COUNT(*) WHERE status = 'Cancelled'

📈 DAILY SALES CHART:
--------------------
- Shows revenue per day
- X-axis: Dates (Oct 01, Oct 02, etc.)
- Y-axis: Revenue in Pesos (₱)
- Bar height = Revenue for that day
- Hover to see exact amount

🏆 TOP PRODUCTS TABLE:
---------------------
- Shows top 5 best-selling products
- Sorted by units sold (highest first)
- Shows:
  * Product name
  * Units sold
  * Total revenue from that product

========================================
TECHNICAL DETAILS:
========================================

Form Method: GET
----------------
<form method="GET">
  <input name="start_date" />
  <input name="end_date" />
  <button type="submit">Generate Report</button>
</form>

Why GET instead of POST?
- URLs are bookmarkable
- Can share report links
- Browser back button works
- Can refresh without warning

PHP Code Flow:
--------------
1. Get dates from URL or use defaults:
   $start_date = $_GET['start_date'] ?? date('Y-m-01');
   $end_date = $_GET['end_date'] ?? date('Y-m-t');

2. Query database with date range:
   WHERE DATE(created_at) BETWEEN :start_date AND :end_date

3. Display results in HTML

4. Generate JavaScript for chart

SQL Query Example:
------------------
SELECT 
  COUNT(*) as total_orders,
  SUM(CASE WHEN status = 'Delivered' THEN total_amount ELSE 0 END) as total_revenue
FROM orders 
WHERE DATE(created_at) BETWEEN '2024-10-01' AND '2024-10-31'

========================================
COMMON QUESTIONS:
========================================

Q: Why is total revenue ₱0.00?
A: No Delivered orders in that date range.
   - Check if you have orders in database
   - Make sure orders are marked as "Delivered"
   - Try a wider date range

Q: Why do I see "No sales data"?
A: No products were sold in that period.
   - Check order_items table
   - Make sure orders exist
   - Try "All Time" (very wide date range)

Q: Can I export the report?
A: Currently no, but you can:
   - Take a screenshot
   - Copy data from table
   - Use browser's Print to PDF

Q: Does it update in real-time?
A: No, you must click "Generate Report" to refresh.
   - Each click queries database again
   - Shows latest data at that moment

Q: What if end_date is before start_date?
A: You'll get no results (empty report).
   - Always set start_date before end_date
   - System doesn't validate this yet
