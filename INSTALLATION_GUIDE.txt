========================================
  DINECLICK - INSTALLATION GUIDE
========================================

QUICK START - 5 STEPS:
======================

1. START WAMP SERVER
   - Open WAMP64
   - Wait for icon to turn GREEN
   - If orange/red, click icon → Apache → Service → Start/Resume Service

2. CREATE DATABASE
   - Open browser: http://localhost/phpmyadmin
   - Click "New" on left sidebar
   - Database name: dineclick_db
   - Collation: utf8mb4_unicode_ci
   - Click "Create"

3. IMPORT DATABASE SCHEMA
   - Select "dineclick_db" database (click on it)
   - Click "Import" tab at top
   - Click "Choose File"
   - Navigate to: c:\wamp64\www\DineClick\database\schema.sql
   - Click "Go" at bottom
   - Wait for success message

4. VERIFY FOLDER STRUCTURE
   - Ensure this folder exists: c:\wamp64\www\DineClick\assets\images\products\
   - If not, create it manually

5. ACCESS THE SYSTEM
   
   USER ACCESS:
   - URL: http://localhost/DineClick/login.php
   - Click "Create your DineClick Account!"
   - Register with your details
   
   ADMIN ACCESS:
   - URL: http://localhost/DineClick/login.php
   - Email: admin@dineclick.com
   - Password: admin123

DETAILED INSTRUCTIONS:
========================================

IF DATABASE CREATION FAILS:
---------------------------
1. Open phpMyAdmin SQL tab
2. Paste this command:
   CREATE DATABASE IF NOT EXISTS dineclick_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
3. Click "Go"
4. Then import schema.sql as described above

IF IMAGES WON'T UPLOAD:
----------------------
1. Check folder exists: c:\wamp64\www\DineClick\assets\images\products\
2. Right-click folder → Properties → Security
3. Make sure "Users" has "Write" permission
4. If issues persist, run WAMP as Administrator

IF YOU SEE "CONNECTION ERROR":
------------------------------
1. Open: c:\wamp64\www\DineClick\config\database.php
2. Check these settings match your MySQL:
   - Host: localhost (usually correct)
   - Database: dineclick_db
   - Username: root (WAMP default)
   - Password: (empty for WAMP default)
3. If you changed MySQL password, update it here

IF PAGES SHOW BLANK/WHITE:
-------------------------
1. Open: c:\wamp64\bin\apache\apache2.x.x\bin\php.ini
2. Find: display_errors = Off
3. Change to: display_errors = On
4. Restart WAMP
5. Reload page to see actual error message
