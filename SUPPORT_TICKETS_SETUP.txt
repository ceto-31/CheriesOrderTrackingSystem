===============================================
DINECLICK SUPPORT TICKETS SYSTEM - SETUP GUIDE
===============================================

This guide will help you set up the support ticket system.

STEP 1: CREATE DATABASE TABLES
-------------------------------
1. Open phpMyAdmin or your MySQL client
2. Navigate to the 'dineclick_db' database
3. Run the SQL file: database/support_tickets.sql

   OR copy and paste this SQL:

   USE dineclick_db;

   CREATE TABLE IF NOT EXISTS support_tickets (
       id INT(11) PRIMARY KEY AUTO_INCREMENT,
       user_id INT(11) NOT NULL,
       subject VARCHAR(200) NOT NULL,
       category VARCHAR(50) NOT NULL,
       status ENUM('Open', 'In Progress', 'Resolved', 'Closed') DEFAULT 'Open',
       priority ENUM('Low', 'Medium', 'High') DEFAULT 'Medium',
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
       updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
       FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
       INDEX idx_user_ticket (user_id),
       INDEX idx_status (status),
       INDEX idx_created (created_at)
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

   CREATE TABLE IF NOT EXISTS support_messages (
       id INT(11) PRIMARY KEY AUTO_INCREMENT,
       ticket_id INT(11) NOT NULL,
       sender_id INT(11) NOT NULL,
       is_admin TINYINT(1) DEFAULT 0,
       message TEXT NOT NULL,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
       FOREIGN KEY (ticket_id) REFERENCES support_tickets(id) ON DELETE CASCADE,
       FOREIGN KEY (sender_id) REFERENCES users(id) ON DELETE CASCADE,
       INDEX idx_ticket (ticket_id),
       INDEX idx_created (created_at)
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

STEP 2: VERIFY FILES
--------------------
Make sure these files exist in your installation:

User Side:
- support.php (User support ticket interface)
- help.php (FAQ page)
- includes/sidebar.php (Updated with notification badge and support link)

Admin Side:
- admin/support_tickets.php (Admin ticket management interface)

Database:
- database/support_tickets.sql

STEP 3: TEST THE SYSTEM
-----------------------
1. Login as a regular user
2. Click "Contact Support" in the sidebar
3. Create a new support ticket
4. Add a message

5. Login as admin (admin@dineclick.com)
6. Navigate to "Support Tickets" in admin sidebar
7. View and reply to the ticket
8. Update ticket status
